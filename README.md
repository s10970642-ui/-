# 📒 單字背背

背筆記本單字用的小工具，單一 `index.html`，不需要安裝任何東西。

## 使用方式

直接用瀏覽器打開 `index.html`（手機、電腦都可以）。

## 功能

- **單字表**：搜尋、⭐ 加星號、🔊 發音、看每個字的熟練度、新增自己的單字
- **字卡**：點一下翻面，按「記得 / 不熟」；不熟的字會在幾張後再出現，可切換成先看中文
- **選擇題**：每輪 10 題，看英文選中文 / 看中文選英文 / 混合
- **拼字**：看中文拼出英文，可用提示逐字母顯示
- **練習範圍**：全部、還不熟的、加星號的（筆記上打勾的字預設已加星號）

熟練度（0–5）會存在瀏覽器裡，答對 +1、答錯歸零，熟練度低的字會優先出題。

## 新增單字

可以在「單字表 → 新增單字」直接加，或修改 `index.html` 裡的 `BASE_WORDS` 清單。
